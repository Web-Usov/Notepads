# Plainix brand assets

Use **Plainix** as the product name. For a short description, use “Text editor” in English or «Текстовый редактор» in Russian.

| Windows package and shell | [Packaged icon and tile resources](../../src/Notepads/Assets/) |

The logo has two lines of text and an amber caret. The SVGs contain outlined lettering. Leave at least one stroke thickness of clear space around the artwork. For small Windows icons, use the packaged rasters fitted to the pixel grid.

Graphite (`#292A28`) and paper (`#F8F5EF`) are the main surfaces. The caret in the logo uses amber (`#EF820E`). For interface accents on light backgrounds, use dark amber (`#9A4B00`).

To use the link preview, open the repository’s **Settings → General → Social preview** and upload the PNG above. GitHub reads the README banner directly from the repository.
